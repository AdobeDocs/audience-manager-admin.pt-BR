# Atribuir um usuário do portal a um usuário do Tableau {#assign-a-portal-user-to-tableau-user}

<!-- t_tabeau.xml -->

Use a página [!UICONTROL Reporting] para tornar um usuário do portal um usuário [!DNL Tableau]. Isso permite que os usuários visualizem relatórios de [!DNL Tableau] no Audience Manager.

1. Clique em **[!UICONTROL Reporting]** > **[!UICONTROL Assign Portal User to Tableau User]**.

   ![](assets/tableau.png)

1. Para atribuir um usuário, na linha de parceiro desejada, digite um nome de usuário [!DNL Tableau] no campo de texto e clique fora do campo de texto.

Para excluir uma atribuição de usuário, na linha de parceiro desejada, remova o nome de usuário do campo de texto e clique fora do campo de texto.
