# Visão geral de formatos {#formats-overview}

Um formato é um modelo salvo (ou arquivo) que usa macros para organizar o conteúdo dos dados enviados para um destino. Os tipos de formatos incluem [!DNL HTTP] formatos e formatos de arquivo. Os formatos [!DNL HTTP] enviam dados em um objeto [!DNL JSON] com um método [!DNL POST] ou [!DNL GET]. Os formatos de arquivo enviam dados em um arquivo por [!DNL FTP]. As macros usadas por cada formato permitem definir nomes de arquivo, definir cabeçalhos de arquivo e organizar o conteúdo de um arquivo de dados. No Admin [!DNL UI], é possível criar, salvar e reutilizar formatos ao configurar destinos para clientes.
